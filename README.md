# dashboard

React (Vite) frontend for CopyM Pay Dashboard built with Tailwind CSS, Lucide icons, and Palanquin typography.

## Features
- **Dashboard**: Features high-fidelity black balance card, 3D quick action cards (Deposits, Payout, Swapp), and Recent Activity ledger.
- **Deposits Hub**: Comprehensive deposit flow management with status filters (`All 1,248`, `Awaiting 36`, `Confirming 8`, `Credited 1,174`, `Expired 18`, `Exception 12`), network dropdown, and CSV export.
- **Uniform Page Structure**: Standardized `[Page Title]` and `[Category] > [Page Title]` navigation header across all routes.
- **Interactive Modals**: Developer API Key vault (`Key`, `Lock`), Webhook tester (`Play`), Secret rotation (`RotateCcw`), and Blockchain Explorer inspection (`ExternalLink`).

## Getting Started

### 1. Install dependencies:
```bash
pnpm install
# or
npm install
```

### 2. Run the development server:
```bash
pnpm run dev
# or
npm run dev
```

### 3. Build for production:
```bash
pnpm run build
# or
npm run build
```
